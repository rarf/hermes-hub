# Profile template: `casa`

Neutral starter config for the isolated `casa` Hermes profile (family / home /
couple domain). Keeps Casa/Márcia context separate from the work baseline.

## Skills to enable
- family-ops-casa
- coaching-casamento

## Plugins enabled
- optmem (memory), lifeos (cockpit, scoped to Família/Casa domains)

## Notes
- Switch in with `hermes profile use casa`; return with `hermes profile use default`.
- Finances and Todoist are intentionally OUT of this profile (finances = local
  financas app; Todoist only outside family/casa scope).
- Vault sync: the Obsidian vault mirrors Família/Casa domain notes; see
  docs/vault.md.
